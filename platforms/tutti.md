# Tutti

- 官网：https://tutti.so
- 规则原文：https://tutti.so/docs/conduct 、https://tutti.so/docs （Boost rewards / Boosting well）
- 更新日期：2026-09-24

## 平台机制

Tutti 连接品牌方和 X 创作者。回复、引用、转发他人的活动推文属于 Boost，单独有一个奖池，按互动和曝光瓜分，不是固定单价。回复和引用在评分里权重最高。结算后以 USDC 提现。

## 硬性规则（违反会永久移除）

- 禁止自动化互动：不能用脚本自动回复、引用或 Boost。每一次互动都必须是真人主动选择。本 Skill 只起草文案，由用户手动发布。
- 原创性：不能照搬原帖的结构、完整句子或核心例子；换几个词或加 emoji 也算抄袭。
- AI 内容：全文由模型生成、没有作者本人经验或判断的内容不算原创。可以用 AI 做调研、理结构、改措辞。所以每条文案都必须有一个属于账号主人的具体观点、问题或使用场景。
- 低质互动：禁止空洞转发（只写"nice"或单个 emoji）、只放链接、复制粘贴模板、纯 emoji 回复、与原帖无关的内容。
- 不要联系或 @ 品牌方，原帖已经 @ 的除外。

## 写作要点

- 回复要让作者和其他读者愿意接着聊：优先提一个具体问题，或补一个原帖没提到的角度。
- 引用要能独立成立：没看过原帖的人读完也知道这个产品或观点是什么、为什么值得看。
- 同一活动的多个任务之间，用词和结构都要换，不要形成固定模板。
