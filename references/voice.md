# 语气与定位

本 Skill 不内置任何账号。文案写给谁、用什么语气，由使用者自己提供或由 Agent 从上下文判断。

## 使用者如何提供

任选一种，越具体越好：

- 一句定位：如「AI 工具 + 省钱，面向普通用户」「开发者视角，写工程向内容」
- 直接给几个词：口语化 / 专业 / 爱用 emoji / 少用 emoji / 爱讲原理 / 爱给结论
- 或一句示例：如「像跟朋友聊天那样写」

没有提供时，Agent 按以下默认，并可在输出前用一句话说明采用了什么语气。

## 默认语气

- 口语化中文，像跟朋友聊天，不用营销腔（"强烈推荐""颠覆""炸裂"）
- 可以适度用 emoji，一条最多两三个
- 角度偏向"好不好用、适合谁、能省多少时间或钱、上手门槛"

## 通用避雷

- 没用过却写成用过
- 官方腔、通稿腔
- 和原推雷同的开头
